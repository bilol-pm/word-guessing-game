# 🎮 Python Word Guessing Game

Python tilida yaratilgan qiziqarli va interaktiv konsol o'yini (CLI). Bu loyiha dasturlash mantiqini, sikllarni, shartli operatorlarni va lug'atlarni (`dictionaries`) amalda mustahkamlash uchun mo'ljallangan.

## 🌟 O'yin Xususiyatlari:
* **Sirli podskazkalar:** Har bir yashirin so'z uchun 2-3 so'zdan iborat o'ylantiradigan ishoralar beriladi.
* **Ikki bosqichli o'yin:** 
  1. Avval butun so'zni bir urinishda to'g'ridan-to'g'ri topish imkoniyati.
  2. Agar topolmasangiz, klassik harfma-harf topish rejimiga o'tiladi.
* **Urinishlar nazorati:** Jonlar faqat xato harf kiritilganda kamayadi.
* **Qayta o'ynash tsikli:** O'yin tugagach, dasturdan chiqmasdan yana qaytadan o'ynash imkoniyati.
